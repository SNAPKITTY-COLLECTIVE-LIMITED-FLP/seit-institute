## The Sovereign AI Standard

SEIT certifies AI systems across three tiers:

| Tier | Mark | Requirement |
|------|------|-------------|
| I | Observer | Adversarial resilience + public audit log |
| II | Sovereign | All 5 criteria + cryptographic proof + WORM ledger |
| III | Igneous | Sovereign + stochastic resilience + sealed manifest + annual audit |

**Five criteria for Sovereign AI:**
1. **Computational Independence** — local inference, no cloud AI API dependency
2. **Cryptographic Sovereignty** — hardware-derived keys, no vendor KMS
3. **Immutable Audit Trail** — append-only WORM ledger, no deletions
4. **Structural Governance** — rules enforced in code, not policy
5. **Adversarial Resilience** — recursive defense against injection and manipulation
